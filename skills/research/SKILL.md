# Research that holds up

1. Plan 3–5 searches with different angles (the thing itself, reviews/comparisons, the
   official source, recent news). `web_search`, then `fetch_url` the 3–6 best results.
2. Prefer primary sources (maker, government, the paper itself) over aggregators; note dates.
3. Keep a scratch list of facts with the URL each came from. Never state a number, price or
   quote you didn't read on a page in this run.
4. When sources disagree, say so and say which you trust and why.
5. The note's first page answers; sources go on a later page as `::link[Title]{url=…}`.
6. Prices and availability change: say "as of <today>".
