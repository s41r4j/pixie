# Integration examples

- `preview/index.html`: open this directly for the interactive local style viewer.
- `../tokens/openclicky.css`: load as shared Tauri/React CSS variables.
- `../tokens/tokens.ts`: import TypeScript tokens.
- `../assets/platform/macos/OpenClicky-default.icns`: macOS bundle icon.
- `../assets/platform/windows/OpenClicky-default.ico`: Windows bundle icon.
- `../assets/platform/macos/tray-template-22.png` & `...44.png`: monochrome menu bar templates.
- `../assets/system-icons/svg`: use the SVG glyphs as `img` sources or React components.
- `../assets/microphone-states/svg`: use the distinct states rather than recoloring one mark.
- `../assets/audio`: user-toggleable short soft sounds; always default off in sensitive applications.

All colors come from `tokens/tokens.json`. No third-party font binaries are included.
