# M1 — shell

Exit criterion (BUILD-SPEC §10): hotkey opens/closes panel; a sound plays on open.

## Plan

1. Workspace skeleton per §3 (`apps/`, `crates/`, `resources/`, `skills/`, `docs/`).
2. `core::resources` — slot manifest loader (variants, gain, category, bed), path-escape
   guard, missing-file report; never panics.
3. Placeholder generator — original media for every §8 slot so the app runs without real media.
4. `voice::bus::AudioBus` — category gains, bed mutual exclusion; rodio backend on its own thread.
5. Desktop shell — accessory app (no Dock), tray, notch panel (status level, all Spaces,
   excluded from capture, shown without taking focus), `slot://` protocol for UI media.
6. Hotkey — poll `CGEventSourceFlagsState` for ctrl+option (no permission needed).
7. Permissions wizard — Mic, Screen Recording, Accessibility, Speech, Files: detect, request,
   deep-link to System Settings.
