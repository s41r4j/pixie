Before you start

  • macOS 14 or newer, Apple silicon or Intel
  • A Claude, OpenAI or DeepSeek API key
  • Mic, Screen Recording and Accessibility (the welcome window walks you through)
First launch: right-click Pixie → Open once. Builds without an Apple Developer ID ask you to confirm.

Build it from source
git clone https://github.com/s41r4j/pixie && cd pixie
npm ci
npm run app:build      # target/release/bundle/macos/Pixie.app + .dmg
npm run app:install    # copy to /Applications and open
# needs Xcode command-line tools, Rust stable, Node 20+
# verify a release: shasum -a 256 -c SHA256SUMS.txt
Install

Three little steps.

About a minute, then the welcome window takes over.

01

Download

Grab the universal .dmg above.

02

Drag to Apps

Open it and drag Pixie into Applications. First launch: right-click → Open.

03

Say hello

Allow the switches, paste a key, test your mic. The natural voice downloads while you go.
