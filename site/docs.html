Install

Download the .dmg, drag Pixie to Applications, then right-click → Open the first time. (Windows .exe and Linux .AppImage previews are on the Download page; on Windows turn on Settings → Privacy & security → Speech → Online speech recognition so Pixie can hear you. What works where.) The :) appears in the menu bar and the welcome window starts: your name, permissions, a model key, a mic test, and the shortcuts. The natural voice downloads in the background while you go.

Screen Recording needs a relaunch after you allow it. If a switch is on but Pixie says "not allowed", use Reset in Settings → Permissions.

Models and keys

Settings → Models: pick a provider, paste its key. Models load live from the provider, newest first, with context size and price. Mark one for talking (T), one for agents (A), and optionally one fallback that answers if the main model fails. If a model can't see screenshots, the page says so.

Settings → Usage shows tokens and cost per model, with tokens read from the provider's prompt cache counted separately (they cost a fraction). Pixie keeps prompts cache-friendly and sends only the part of the screen a question needs, so most of each step is a cheap cache read.

No key? Install opencode, then Settings → Models → On this computer: pick one of its Free models for talking and agents (or say “use opencode”). Pixie starts opencode only when needed and stops it when quiet, keeps it apart from your own opencode setup, and turns its shell and file tools off; Pixie's own tools still work. Free models have daily limits set by opencode; when one runs out, Pixie tells you. Claude Code and Codex subscriptions can't be used as Pixie's model under their makers' terms; Pixie still hands coding tasks to them.

Change the keys in Settings → General → Shortcuts, or just ask: “make dictation ctrl shift”. On Windows the keys are CtrlAlt to talk and CtrlWin to dictate.

The short ones (quit, stop working, never mind, new chat, switch to Eon) work instantly without asking the model. API keys, permissions and Google sign-in can't be changed by voice: Pixie opens the page for you.

The buddy

The round :) rides just off your pointer. It points at real controls by name, draws circles, underlines and selections, and clicks or types when you ask. For a task of several steps (“open System Settings, go to General, then About”) Pixie reads the screen again after every action and keeps the same name for each button for the whole request, so step four lands on the right control. A click by a control’s id goes to that exact control (scrolled into view first), and each step says what it really landed on. Before anything that deletes, sends, buys or can’t be undone (Delete, Send, Move to Trash, Return in a chat, a command like rm -rf), a dialog asks you: Allow or Don’t, and nothing happens without Allow. Longer tasks go to a live agent. If your model can't see screenshots, Settings → Models says so. Settings → General: Always on, Idle (only while Pixie is busy) or Off; and whether it may click for you.

Memory and today's chat

Today's chat carries on all day: after a quiet hour or a restart, Pixie still knows what you were talking about (and how long it's been). It ends when you press New chat in the notch, say “new chat”, or the day changes: at midnight, or the hour you pick in Settings → Memory. The last 12 turns go to the model in full and older ones as a short summary, so long days stay quick. Every chat is kept in the Jobs window.

Long-term memory is a set of short notes about you: who you are, how you like answers, your people, projects and setup. Say “remember that…” or “forget…”. On Automatic, Pixie also reads a chat once it's been quiet for a few minutes and keeps anything lasting; Only when I ask keeps just what you tell it; Off stops reading and writing notes. The most useful notes go with every question and Pixie searches the rest when they matter. In Settings → Memory you can add, edit (click a note), search and forget notes, or forget everything. Notes live in memory.json on your computer; passwords, keys and card numbers are refused.

Agents

Background agents work on their own (research, documents, files, code) and keep a live note. Live agents do the task on your screen and explain each step. Both show in the notch's Agents tab; past jobs and chats are in the Jobs window. Agents never overwrite your files and can't touch .ssh, .aws, keychains or .env files.

Pick the default agent, a model per agent, sandbox and permission modes in Settings → Coding.

When a task doesn't name an agent, Pixie picks one with usage left: your default first, then Codex, Claude Code, and opencode's free models when the paid ones are out. Codex's 5-hour and weekly limits are read from its own logs; set Claude Code's in Settings → Coding → Usage left on your plans. Each job remembers which agent did the work, and you can ask Pixie how a job is going.

Apps and accounts

Settings → Apps switches on Calendar, Reminders, Contacts and Apple Mail; each asks macOS once. Then just ask: “what's on tomorrow?”, “remind me to call Sam at 5”, “draft a reply to Alex”. Drafts open for you to send; Pixie never sends mail.

Google: create an OAuth client of type Desktop app in Google Cloud, enable the Gmail and Calendar APIs, paste the client ID and secret, and sign in. Pixie reads Gmail, saves drafts and reads or adds events; tokens stay on your Mac.

Connectors

Connectors are experimental: turn them on in Settings → Experimental → Connectors (or say “turn on connectors”). Off, the page is hidden, no connector servers run and Pixie isn't offered their tools; it starts on if you'd added connectors before 0.8.0. Then Settings → Connectors gives Pixie tools from other services, grouped by what they're for. Each card says how it signs in and whether it's working.

A green dot means connected, with the number of tools; What it can do lists them. If one can't connect, the card says why in plain words, with Retry and the server's own message under Details. Add your own server takes any MCP server's command (and environment, one KEY=value per line) without editing mcp.json by hand. Connectors run through Node.js; tokens stay on your computer. Pixie asks before anything that posts, sends or deletes.

Updates

Pixie updates itself from GitHub. It checks when it starts and every six hours, downloads a new version in the background, checks its signature, and switches over when you aren't using it. Settings → About shows where it is and has Check now and Restart now; the menu-bar menu has Check for Updates. Turn off Update automatically to decide yourself.

Canvas

When a picture explains it better, Pixie draws on a real Excalidraw canvas in its own window: boxes, arrows, text, or a Mermaid flowchart laid out for you. Everything stays editable. Name it at the top and save it as .excalidraw, PNG or SVG (to Downloads, never overwriting; Show reveals the file).

How often: Settings → General → Drawing: Only when I ask, When it helps (the default: flows, steps, how things connect) or Often. Or say “draw more” or “only draw when I ask”.

The window comes up in front of you, also over a full-screen app, and goes away when you click outside it. Bring it back with Show Canvas in the menu-bar menu, or ask: “open the canvas”, “open my git canvas”, “list my canvases”. Pixie can read your edits back (“add a database box under the server”), clear a canvas, or delete one or all of them; Delete in the canvas does it too (click twice), and deleted canvases go to the Trash.

Drawing while it talks: when Pixie explains something on your screen, each circle, box, arrow or pointing move appears the moment the sentence about it is spoken. Ask it to “explain”, “teach me” or “walk me through” and it takes four to eight sentences instead of one or two.

3D (experimental): turn on Settings → Experimental → 3D explanations, then ask for something in 3D (“show me how a heart pumps, in 3D”). A window opens with a model of labelled shapes and arrows: drag to spin, scroll to zoom, right-drag to move. As Pixie explains, the view turns to each part and lights it up. Closing the window frees its memory.

Several screens: Pixie knows which screens you have and looks at the one your pointer is on. Ask about another (“what's on my other screen?”, “the laptop screen”, “both screens”) and it looks there too. Live agents stay on the screen of the app they work in, and a window that crosses two screens keeps all its controls. Settings → General → Notch on keeps the notch on one screen (the built-in one, or any by name). Ask about “my other desktop” and Pixie knows which windows are there.

Laid out for you: ask for an org chart, a mind map, a timeline, an architecture in layers, a cycle, pros and cons, a 2×2, a bar, line, pie or scatter chart from your numbers, a table, sticky notes, a code block or a wireframe of a page or a phone screen, and Pixie places everything itself. Ask it to change a drawing (“make the CEO box red”, “remove the CFO”, “move sales to the right”) and it edits the shapes that are there; arrows follow. While it explains, the canvas glides to the part each sentence is about.

3D (Settings → Experimental): models built from boxes, spheres, tubes, spun and pushed-up shapes and gears, in matte, metal, glass or glowing materials, with parts that spin, orbit, pulse and flow. Explode pulls the parts apart, Cut slices the model open, Pause stops the motion and Reset shows the whole thing again; Pixie can explode and cut it while it talks.

A personality changes only how replies sound: same voice, same tools, same care before sending or deleting. Documents and reports that agents write keep the plain style.

Voice and sounds

The natural voice runs offline (about 370 MB, downloaded during setup); the system voice works meanwhile. To stay light it loads when you start talking (about a second, while you speak) and unloads after five quiet minutes, so Pixie uses about 215 MB when idle. Pixie works out how to say each word itself, so names, new words, numbers, times and prices are all spoken (“$12.50” is “twelve dollars fifty cents”). Settings → Voice → Loudness has Quiet, Normal and Loud for a busy room; “speak louder” works too. Settings → Sounds lets you change, quieten or replace every sound with your own file.

Pixie’s speech to text: Settings → Voice → Listening → Download (about 73 MB, once). Dictation then uses Pixie’s own engine, on your computer and the same on Mac, Windows and Linux: the words go into the text field as you say them, and punctuation and capitals are tidied when you stop. It’s English for now, and it’s separate from your Mac’s own Dictation. Use it for chooses dictation only or talking to Pixie too; Type as I speak off puts the text in when you stop; System speech to text goes back to the recogniser that comes with your computer.

Privacy

Speech recognition, screen OCR and the natural voice run on your Mac. Screenshots and your words go only to the model provider you chose, with your key. Chats, memory notes, canvases and usage are kept locally; you can delete any of them. There is no Pixie server.

Troubleshooting

"Can't be opened": right-click → Open, or System Settings → Privacy & Security → Open Anyway. Permission not sticking: Settings → Permissions → Reset, allow, relaunch. Asked for permissions again after updating to 0.8.1: Pixie has a new app ID (pixie.s41r4j.in), and macOS keeps permissions per app ID, so allow them once more; your settings and data came along. No answer: check the key in Settings → Models. Pixie remembers something wrong: say “forget that…”, or delete the note in Settings → Memory. The canvas vanished: it hides when you click outside; Show Canvas in the menu-bar menu brings it back. Pixie draws too much: Settings → General → Drawing → Only when I ask. Something seems broken: say “check yourself”, or Settings → About → Run a checkup; Pixie checks its helper, permissions, model, voice and disk, and fixes what it can. It also watches itself: a part that hangs is restarted (three times in five minutes and it's left alone, and you're told), a permission you turned off is named with its page opened, a retired model is swapped for the newest of its family, and an update that keeps closing at launch is rolled back to the version before. Tell the developers: say “report this” (and which browser you use GitHub in), or Settings → About → Report a problem. A GitHub issue opens filled in, with personal paths, keys and emails removed; you read it and press Submit. Pixie keeps a log and a list of problems it worked around in its support folder, and never sends them anywhere itself. Still stuck? Open an issue.
